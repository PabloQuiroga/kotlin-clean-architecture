# ADR 003: Uso de Koin para Inyección de Dependencias

## Estado
Aceptado

## Contexto
Para mantener el desacoplamiento entre capas, las clases no deben instanciar sus propias dependencias (ej: el UseCase no debe crear el Repositorio).

## Decisión
Implementar la Inyección de Dependencias (DI) utilizando la librería **Koin**.

## Justificación
- **Simplicidad**: Koin es la librería de DI más ligera y sencilla de configurar para Kotlin.
- **Desacoplamiento**: Permite cambiar la implementación de un repositorio por un "Mock" durante los tests sin tocar la lógica de negocio.

## Consecuencias
- Introduce una dependencia externa al proyecto.
