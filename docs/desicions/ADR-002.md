# ADR 002: Uso de Kotlin Coroutines y Flow

## Estado
Aceptado

## Contexto
La sincronización de tareas implica llamadas a APIs y operaciones de disco, que son lentas y pueden bloquear el hilo principal de la aplicación.

## Decisión
Utilizar **Kotlin Coroutines** para la gestión de hilos y **Flow** para el manejo de flujos de datos asíncronos.

## Justificación
- **Eficiencia**: Las corrutinas son "hilos ligeros", permitiendo miles de tareas concurrentes sin agotar la memoria.
- **Lectura**: Permiten escribir código asíncrono que se lee la manera secuencial, eliminando el "Callback Hell".
- **Estándar**: Es la herramienta oficial y la base fundamental para el desarrollo moderno en Android.

## Consecuencias
- Requiere la gestión de `CoroutineScopes` para evitar fugas de memoria al cerrar la aplicación.
